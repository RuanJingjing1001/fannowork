# 环境插件接入规范

一个新环境插件必须实现 `WorkflowEnvironment` 的六个方法，并满足以下条件：

- `prepare` 在干净运行目录中创建任务实例，固定所有影响结果的软件与数据版本；
- `observe` 只返回 agent 获准看到的状态和动作描述；
- `act` 对未知、越权或无效动作返回结构化失败，不泄漏评分器私有信息；
- `snapshot` 生成稳定、可哈希的 evaluator 视图；
- `reset` 恢复与首次 prepare 等价的业务初态；
- `close` 释放容器、VM、进程、端口和临时凭据，并保留审计产物。

插件接入注册表前至少证明：初态可重复、合法动作改变状态、非法动作被拒绝、参考解通过、负例失败、reset 后状态摘要与初态一致。

外部项目的代码可以被研究、抽取或改造，但最终插件应使用本项目命名和契约。来源版本及修改记录写入环境 `metadata`，不进入核心控制流。
